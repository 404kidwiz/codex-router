- **A failed client publication now says which client was left behind and why.** When a picker change, provider toggle, or catalog refresh could not republish one client, the error relayed that publisher's raw crash output nested inside the control process's own, and the Control Center then hid the one line that explained it whenever the cause mentioned a credential. The error now reads `<Client> was not updated.`, followed by the publisher's innermost error message on its own line, so the Control Center always names the client that failed and the terminal shows the cause.
